# Trent — Unreal Engine Co-Dev Partner

I'm an Unreal Engine developer focused on helping game teams design and implement polished gameplay and UI systems.

Through **Dreamboy Games**, I’m building a co-development practice around Unreal Engine 5, with a focus on:

- Game UI / UX implementation
- UMG and Common UI systems
- Blueprint and C++ gameplay systems
- HUDs, menus, and motion design
- Stylized interactive experiences
- Production-ready Unreal workflows
